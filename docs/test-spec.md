# テスト仕様書（社内規則 Q&A）

このファイルは `scripts/TestReport.cs` がテストコードの説明（`[Spec]` 属性）から自動で作ります。直接編集せず、テストの `[Spec]` を直してください。
最新の実行結果は、`scripts/publish.ps1` を実行すると `RuleQA-latest/test-report.md` に出力されます。CI では成果物 `test-report` に保存されます。

## 1. 目的と範囲

業務ロジック（`src/RuleQA.Core`）が仕様どおりに動くことを、自動テスト（xUnit）で確認します。
AI の接続先は偽の HTTP サーバーに置き換え、ファイルはテストごとの一時フォルダに作るので、外部の環境がなくても同じ結果になります。

### 自動テストの対象外（手動で確認する項目）

| 項目 | 確認方法 |
|---|---|
| 画面の表示と操作（Blazor） | `RuleQA-latest/RuleQA.exe` を起動してブラウザで操作する |
| 実際の AI（Ollama・Gemini など）との接続 | 設定画面の「接続テスト」 |
| 配布用 zip の展開と起動 | `scripts/publish.ps1` の実行後に exe を起動する |

## 2. テスト項目

### 2.1 AI 連携（OpenAI 互換 API）

| ID | 項目 | 確認内容 | ケース数 |
|---|---|---|---|
| T01-01 | 接続先・モデル・API キー・JSON スキーマを送る | エンドポイント末尾の「/」を補って /chat/completions に送り、モデル名・メッセージ・Bearer 認証・json_schema 指定（名前とスキーマ）・temperature 0 が含まれる。応答の JSON を読み取れる。 | 1 |
| T01-02 | JSON スキーマ非対応の接続先では自動で切り替える | json_schema が HTTP 400 で拒否されたら json_object、それも拒否されたら形式の指定なしで送り直して成功する。API キーが空なら認証ヘッダーを付けない。 | 1 |
| T01-03 | Azure OpenAI には api-key ヘッダーで送る | 接続先が Azure OpenAI（*.openai.azure.com）なら、API キーを api-key ヘッダーで送り、Bearer 認証は付けない。モデル名（デプロイ名）はそのまま送る。 | 1 |
| T01-04 | temperature を受け付けないモデルでは指定を外す | temperature の指定が HTTP 400 で拒否されたら、temperature だけを外して送り直す（JSON スキーマ指定は残す）。 | 1 |
| T01-05 | JSON でない応答には 1 回だけ出し直しを頼む | 1 回目の応答が読み取れないとき、1 回目の応答と読めなかった理由を会話に足して出し直させ、2 回目の応答を使う。 | 1 |
| T01-06 | 出し直しても読めなければ諦める | 2 回目の応答も読み取れなければ、それ以上は送らずに読み取りの失敗（FormatException）を返す。 | 1 |
| T01-07 | 接続先のエラーを分かる形で伝える | HTTP 401 などのエラーでは、ステータスコードと接続先のメッセージを含む例外にする。 | 1 |
| T01-08 | 埋め込みを入力の順に正規化して返す | /embeddings にモデル名と入力を送り、応答の index の順に並べ直して、長さ 1 に正規化したベクトルを返す。 | 1 |
| T01-09 | AI と埋め込みモデルは設定したときだけ使う | 「使わない」ならチャットも埋め込みも作らない。OpenAI 互換でも埋め込みモデルが空欄なら埋め込みは作らない（キーワード検索のみ）。 | 1 |
| T01-10 | 接続テストでチャットと埋め込みを確かめる | チャットの応答（JSON の message）と埋め込みの次元数を「成功」として示す。接続先がエラーなら例外にせず「失敗」と理由を示す。 | 1 |

### 2.2 設定

| ID | 項目 | 確認内容 | ケース数 |
|---|---|---|---|
| T02-01 | 初期設定は AI なし | 設定ファイルがないときは「AI を使わない」で、埋め込みモデルは空欄になる。 | 1 |
| T02-02 | API キーを暗号化して保存する | 保存したファイルに API キーの平文は含まれず、読み込み直すと元の API キーと接続先に戻る。 | 1 |
| T02-03 | 読み出せない API キーは空欄にする | 別のユーザーや PC で暗号化された値・壊れた値は、例外にせず空欄として読み込む。 | 1 |
